## 2026-11-02 — Cambio de contraseña self-service (TASK-300-06)

### Resumen
Implementado endpoint `PATCH /api/auth/password` para cambio de contraseña autenticado, con validación Zod, verificación de contraseña actual mediante bcrypt, hasheo de la nueva contraseña, revocación de todos los refresh tokens del usuario y registro de auditoría.

### Archivos creados/modificados
| Archivo | Cambio |
|---------|--------|
| `backend-users/src/features/auth/auth.validation.js` | Añadido `passwordChangeSchema` (Zod) con política de complejidad: min 8, mayús, minús, dígito, sin espacios |
| `backend-users/src/features/auth/auth.controller.js` | Añadido método `cambiarPassword()`: verifica contraseña actual, rechaza nueva==actual, actualiza `password_hash` (hash via hook beforeUpdate), revoca todos los refresh tokens, registra sesión de auditoría |
| `backend-users/src/features/auth/auth.routes.js` | Registrada ruta `PATCH /api/auth/password` con middleware `auth` + `validate(passwordChangeSchema, "body")` |
| `backend-users/tests/auth.test.js` | 6 tests nuevos: éxito, contraseña actual incorrecta (401), nueva igual a actual (400), política insuficiente (400), sin token (401), cuerpo vacío (400) |
| `docs/api/users.yaml` | Endpoint `/auth/password` PATCH añadido a paths; eliminado de sección PLANIFICADO |
| `TASKLIST.md` | TASK-300-06 → ✅; subtotal FASE 3 → 81.8%; TOTAL → ≈69.8% |

### Backend endpoints implementados
- **PATCH /api/auth/password** — cambio de contraseña self-service (permiso: autenticado). Valida `password_actual` con `bcrypt.compare`, aplica política de complejidad a `password_nueva`, hashea con bcrypt (hook `beforeUpdate` del modelo TbUser), revoca todos los `tb_refresh_tokens` del usuario.

### Tests (6 tests, todos pasando)
1. Éxito: contraseña cambiada, `update` llamado con `{password_hash}`, `RefreshToken.update({revoked:true})` llamado
2. Contraseña actual incorrecta → 401, ningún cambio en BD
3. Nueva contraseña igual a la actual → 400
4. Política de complejidad insuficiente → 400 (Zod validation)
5. Sin token de autenticación → 401
6. Cuerpo vacío → 400 (Zod validation)
