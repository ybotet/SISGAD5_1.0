## Backend endpoints consumidos
- **Usuarios**: `GET/POST/PUT/DELETE /api/user` (permisos `usuarios.ver/crear/actualizar/eliminar`)
- **Roles**: `GET/POST/PUT/DELETE /api/roles` (permisos `roles.ver/crear/actualizar/eliminar`)
- **Permisos**: `GET/POST/PUT/DELETE /api/permisos` (permisos `permisos.ver/crear/actualizar/eliminar`)

## RBAC implementado
- **Frontend**: `ProtectedRoute` en cada pestaña; `AdminPage` filtra tabs según `hasPermission()` del `AuthContext`
- **Backend**: Cada endpoint valida con `tienePermiso("permiso.requerido")` — el frontend **nunca oculta solo en UI**, el backend revalida
