## 2026-10-29 — Refresh tokens (TASK-300-03)

**Tipo:** Feature / Seguridad
**Estado:** ✅ Completada

### Qué se hizo

#### SPEC.md §8.1 — Autenticación con Refresh Tokens

Anteriormente, `login` emitía un único JWT con expiración de 24h. Según SPEC.md:
- **Access token**: 15 min (corta duración)
- **Refresh token**: 7 días, almacenado en BD (`tb_refresh_tokens`)

Se implementó el flujo completo: login (access + refresh), refresh (rotación), logout (revocación).

#### Bug fix — AssociationError duplicate alias `tb_rol`

Durante el server startup, Sequelize lanzaba `AssociationError: You have used the alias tb_rol in two separate associations`. Las asociaciones estaban definidas tanto directamente en `features/index.js` como en los métodos `.associate()` de los modelos, y `index.js` llamaba ambos.

**Solución:** Eliminadas las llamadas a `.associate()` en `features/index.js` (patrón backend-mp — define todas las relaciones directamente en el archivo).

#### Flujo de refresh tokens (rotación)

```
1. Login (POST /api/auth/login)
   ├─ Valida credenciales (Zod + bcrypt)
   ├─ Genera access_token (JWT_SECRET, 15m)
   ├─ Genera refresh_token (JWT_SECRET, 7d)
   ├─ Hash del refresh_token → BD (tb_refresh_tokens)
   └─ Retorna { accessToken, refreshToken }

2. Refresh (POST /api/auth/refresh)
   ├─ Verifica firma JWT del refresh_token
   ├─ Busca refresh_token hasheado en BD → no revocado, no expirado
   ├─ Busca usuario → activo
   ├─ Revoca refresh_token anterior (rotación)
   ├─ Genera nuevos access + refresh tokens
   └─ Retorna { accessToken, refreshToken }

3. Logout (POST /api/auth/logout)
   ├─ Busca refresh_token hasheado en BD
   ├─ Marca `revoked = true`
   └─ Retorna { success: true, message }
```

#### Seguridad
- ✅ Refresh tokens **hasheados** con SHA-256 antes de almacenar (nunca se guarda el token original en BD)
- ✅ Rotación de tokens: el refresh token anterior se revoca al emitir uno nuevo
- ✅ Revocación explícita en logout
- ✅ Expiración automática en BD (`expires_at`)
- ✅ JWT_SECRET validado al arranque (fail-fast, ≥32 chars — SEC-01)
