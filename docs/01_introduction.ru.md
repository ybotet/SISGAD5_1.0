# Введение и контекст - SISGAD5

> **Версия:** 1.0  
> **Дата:** 2026-09-25

---

## 1. Обзор

**SISGAD5** (Система информации для управления и поддержки Дирекции №5) — комплексная платформа, разработанная как дипломная работа в **МГТУ им. Н.Э. Баумана (РФТИ МИРЭИ)** студентом **Ботетом С.Я.**

Система управляет телекоммуникационными процессами Дирекции №5, включая:
- Управление телефонами, линиями и панелями
- Регистрация и отслеживание жалоб
- Технические испытания и рабочие заказы
- Управление материалами и расходами
- Статистика и оперативные дашборды

---

## 2. Организационный контекст

**Дирекция №5** — организационное подразделение, ответственное за телекоммуникационную инфраструктуру. Система заменяет ручные процессы и электронные таблицы цифровым решением.

### Основные актеры
- **Администратор системы** — Настройка и управление пользователями
- **Техник полевой службы** — Выполнение испытаний и работ
- **Оператор кол-центра** — Регистрация и классификация жалоб
- **Начальник отдела** — Надзор и отчёты
- **Аналитик материалов** — Управление запасами и расходами
- **Директор** — Стратегическое видение и KPI
- **Аудитор** — Трассируемость и соответствие

## 3. Объём системы

### Функциональные модули
| Модуль | Описание | Сервис |
|--------|----------|--------|
| Аутентификация | Вход, регистрация, JWT, refresh tokens | Users Service |
| Пользователи и роли | CRUD пользователей, RBAC, разрешения | Users Service |
| Телефоны | CRUD, статусы, история | MP Service |
| Линии | CRUD, статусы, история | MP Service |
| Панели | CRUD, порты, соединения, расположение | MP Service |
| Жалобы | Регистрация, конечный автомат, назначение, аудит | MP Service |
| Испытания | Регистрация, результаты, связи | MP Service |
| Рабочие заказы | Заказы, назначение, время, закрытие | MP Service |
| Материалы | Каталог, категории, единицы | Materials Service |
| Назначения | Множественные позиции, цена в момент, склад | Materials Service |
| Расходы | Регистрация, проверка vs назначения | Materials Service |
| Дашборд | KPI, распределение, оповещения, экспорт | Materials Service |

---

## 4. Техническая архитектура

### Архитектурный стиль
- **Микросервисы** с API Gateway
- **Синхронная** REST/JSON коммуникация
- **База данных на сервис** (3 экземпляра PostgreSQL)
- **Централизованная аутентификация** JWT с refresh tokens

### Технологический стек
| Уровень | Технология |
|---------|------------|
| API Gateway | Node.js + Express |
| Users Service | Node.js + Express + Sequelize |
| MP Service | Node.js + Express + Sequelize + Zod |
| Materials Service | Go + Gin + GORM |
| Frontend | React 18 + Vite + TypeScript + Tailwind |
| База данных | PostgreSQL 15+ |
| Контейнеризация | Docker + Docker Compose |
| CI/CD | GitHub Actions |
| Мониторинг | Prometheus + Grafana + Loki |
