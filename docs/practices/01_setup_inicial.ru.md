## Используемые технологии

### Backend
- Express.js
- Sequelize (ORM)
- PostgreSQL
- JWT (Аутентификация)
- Bcrypt (Шифрование)

### Frontend
- React 18
- Vite
- Material-UI
- Axios

## Начальная настройка

1. **Клонирование/создание проекта**
2. **Выполнить:** `npm run install:all`
3. **Настроить .env** в backend/
4. **Запустить серверы:** `npm run dev`

## Следующие шаги

1. Настроить базу данных PostgreSQL
2. Сгенерировать модели автоматически
