## 1. Идентификация проекта

| Поле | Значение |

---

## 2. Исполнительный обзор

| Аспект | Детали |
|---------|---------|
| **Проблема** | Ручное управление заявками, работами, тестами и материалами в Дирекции №5 с использованием таблиц Excel и бумажных процессов |
| **Решение** | Цифровая платформа с микросервисами для автоматизации полного жизненного цикла телекоммуникаций |
| **Цель** | Централизовать информацию, сократить время реакции, улучшить прослеживаемость и генерировать достоверные KPI |
| **Область применения** | Дирекция №5, ETEM, телекоммуникационная инфраструктура |
| **Пользователи** | 7 акторов: Admin, Техник, Оператор, Руководитель, Аналитик, Директор, Аудитор |

---

## 3. Цели

### 3.1 Цель общая
Разработать комплексную систему, цифровизирующую и автоматизирующую процессы управления, поддержки и анализа телекоммуникационной инфраструктуры Дирекции №5, обеспечивая эффективную, прослеживаемую и ориентированную на данные работу.

### 3.2 Цели конкретные
| № | Цель | Метрика |
|----|----------|---------|
| 1 | Цифровизация регистрации заявок | 100% заявок в системе |
| 2 | Автоматизация потока состояний | 100% потока поддерживается FSM |
| 3 | Управление запасами материалов | Назначение и расход по технику |
| 4 | Генерация KPI в реальном времени | Дашборд обновляется каждые 5 мин |
| 5 | Аудит всех действий | Непрерывный лог критических событий |
| 6 | Управление доступом по ролям | RBAC с 7 определёнными ролями |
| 7 | Предоставление аналитики прогнозирования | Тренды и оповещения настраиваются |

---

## 4. Объём

### 4.1 Включено
- ✅ Аутентификация и авторизация (JWT + RBAC)
- ✅ Управление телефонами, линиями, панелями
- ✅ Регистрация и отслеживание заявок (24 варианта использования)
- ✅ Управление рабочими заказами
- ✅ Регистрация технических тестов
- ✅ Каталог материалов (категории, единицы)
- ✅ Назначение и расход материалов (транзакции ACID)
- ✅ Дашборды и статистика
- ✅ Экспорт отчётов (CSV, PDF)
- ✅ Полный аудит действий
- ✅ Мониторинг и оповещения
- ✅ API Gateway с ограничением скорости

### 4.2 Не включено
- ❌ Интеграция с внешними системами (ERP, CRM) — Будущее
- ❌ SMS/WhatsApp для уведомлений — Будущее
- ❌ ИИ для автоматической диагностики — Будущее
- ❌ Мультитенантность для других дирекций — Будущее

## 6. Допущения

1. Сетевая инфраструктура (волокна, централи) предоставляется ETECSA
2. Исторические данные заявок доступны для миграции
3. Пользователи имеют базовые навыки работы с цифровыми инструментами
4. Доступ в интернет надёжен внутри офисов
5. Базы данных PostgreSQL поддерживаются командой инфраструктуры
6. Корпоративные IP-адреса находятся внутри внутренней сети

---

## 7. Ограничения

| Тип | Ограничение |
|------|-------------|
| **Техническое** | PostgreSQL 15+ (не другая БД) |
| **Техническое** | Микросервисы (не монолит) |
| **Техническое** | Docker + Docker Compose (продакшн: Kubernetes) |
| **Техническое** | Auth через JWT RS256 |
| **Юридическое** | Учебное использование — RTU MIREA |
| **Юридическое** | Персональные данные защищены (Закон о защите данных) |
| **Организационное** | Нет публичного интернета (интранет) |
| **Организационное** | Рабочее время для поддержки (8:00-18:00, Пн-Пт) |
