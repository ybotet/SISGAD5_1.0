## 3. Включения/Расширения

### Include (Обязательные включения)
- UC-02 (Вход) **включает** UC-03 (Обновление токена) — для длительных сессий
- UC-14 (Регистрация жалобы) **включает** UC-12 (Поиск) — для связи телефон/линия/панель
- UC-22 (Создание назначения) **включает** UC-21 (Управление каталогом) — для выбора материалов

### Extend (Опциональные расширения)
- UC-05 (Управление пользователями) **расширяет** UC-07 (Назначение ролей) — опционально при создании
- UC-15 (Управление потоком) **расширяет** UC-16 (Назначение техника) — в зависимости от состояния
- UC-18 (Создание работы) **расширяет** UC-17 (Регистрация испытания) — если требуется предварительное испытание
