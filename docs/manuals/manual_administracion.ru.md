# Административное руководство (SISGAD5)

> **Версия:** 1.0
> **Аудитория:** Руководители отделов, Координаторы, Администраторы
> **Последнее обновление:** Сентябрь 2026

---

## 1. Введение

Это руководство предназначено для пользователей с ролями руководителя, координатора или администратора системы SISGAD5. Описывает функции управления, администрирования пользователей и отчёты.

## 2. Роли и разрешения

### Доступные роли

| Роль | Описание | Основные разрешения |
|-----|-------------|---------------------|
| **Operador** | Регистрирует заявки и управляет инфраструктурой MP | CRUD заявки, тесты, работы (с ограничениями) |
| **Техник** | Выполняет тесты и работы в полевых условиях | Регистрировать тесты, закрывать работы, расходовать материалы |
| **Аналитик MP** | Управляет материалами и дашбордами | CRUD материалы, назначения, расходы, полный дашборд |
| **Руководитель** | Надзирает за операциями | Назначать техников, закрывать заявки, отчёты |
| **Admin** | Полный контроль системы | CRUD пользователи, роли, разрешения |

### Как назначать роли

1. Перейти в **Пользователи** → **Список пользователей**
2. Кликнуть на пользователя
3. Перейти на вкладку **Роли**
4. Выбрать подходящую(ие) роль(и)
5. Кликнуть **Сохранить**

## 3. Управление пользователями

### 3.1. Создание пользователя
1. Перейти в **Пользователи** → **Создать пользователя**
2. Заполнить форму:
   - Имя, фамилия, email
   - Назначить начальную роль
   - Настроить пароль (будет отправлена ссылка для первого входа)
3. Кликнуть **Создать**

### 3.2. Просмотр и поиск пользователей
- Использовать фильтры: имя, email, роль, статус активен/заблокирован
- Пагинация настраивается (10, 25, 50, 100 на страницу)

### 3.3. Назначение ролей
- У пользователя может быть несколько ролей
- Разрешения объединяются (union)

### 3.4. Блокировка/Разблокировка пользователя
- В деталях пользователя → действие **Блокировать**
- Пользователь остаётся заблокированным до ручного разблокирования или истечения времени

## 4. Аналитический дашборд

### 4.1. Основные KPIs (MP)

| Метрика | Описание | Формула |
|---------|-------------|---------|
| Заявки созданы | Всего за день/период | COUNT(quejas) GROUP BY fecha |
| Заявки закрыты | Статус "Закрыта" | COUNT WHERE estado = Cerrada |
| Работы закрыты | Завершённые ордера | COUNT(trabajos WHERE estado = Cerrada) |
| Тесты пройдены | Зарегистрированные тесты | COUNT(pruebas) |
| Tiempo Promedio Cierre | Avg время Открыта → Закрыта | AVG(fecha_cierre - fecha_apertura) |
| Prioridad Distribution | Распределение по приоритету | COUNT GROUP BY prioridad |

### 4.2. KPIs материалов

| Метрика | Описание |
|---------|-------------|
| Asignaciones/Месяц | Всего назначений создано |
| Consumos/Месяц | Всего расходов зарегистрировано |
| Costo Total | Сумма всех расходов |
| Alertas Stock Bajo | Материалы с балансом < минимум |

### 4.3. Как фильтровать дашборд
- **Диапазон дат:** Кликнуть на календарь → выбрать период
- **Сервис:** Выпадающий список для фильтрации по сервису
- **Приоритет:** Флажки для конкретных приоритетов
- **Экспорт:** Кнопка CSV/PDF для отчётов

## 5. Отчёты и экспорт

### 5.1. Создание отчёта по заявкам
1. Перейти в **MP** → **Отчёты** → **Заявки**
2. Настроить фильтры:
   - Дата с / по
   - Сервис
   - Статус
   - Приоритет
   - Техник
3. Выполнить → Экспорт в CSV или PDF

### 5.2. Отчёт по материалам
1. Перейти в **Материалы** → **Отчёты**
2. Выбрать тип: Stock, Asignaciones, Consumos
3. Настроить фильтры и экспортировать

### 5.3. Экспорт дашборда
- Каждый дашборд имеет кнопку **Экспорт** (CSV, PDF, PNG)

## 6. Настройки системы

### 6.1. Типы заявок

| Тип | Вес приоритета | Описание |
|------|----------------|-------------|
| Falla de Señal | 4 | Нет сигнала или сигнал ухудшен |
| Corte de Cable | 3 | Кабель физически перерезан |
| Problema de Equipo | 3 | Неисправность оборудования (ONT, router) |
| Nueva Instalación | 2 | Новая установка |
| Requerimiento | 1 | Улучшение или требование |

### 6.2. Сервисы
- Настраиваются с весом приоритета
- Каждый сервис может иметь связанный SLA

### 6.3. Локации
- Иерархия: País → Departamento → Municipio → Sector
- Каждый уровень имеет настраиваемый вес приоритета

## 7. Настройка минимального запаса

1. Перейти в **Материалы** → **Каталог**
2. Редактировать материал → поле **Минимальный запас**
3. При падении ниже минимума генерируется оповещение на дашборде

## 8. Руководство по администрированию

1. **Проверять дашборд ежедневно:** Проверять оповещения о низком запасе и критических заявках
2. **Аудитировать неактивных пользователей:** Ежемесячная проверка неактивных пользователей
3. **Проверять закрытия:** Перед закрытием заявок проверять связанные тесты и работы
4. **Еженедельные отчёты:** Создавать отчёты о производительности по техникам
5. **Резервные копии конфигураций:** Сохранять экспорт важных конфигураций

## 9. Часто задаваемые вопросы (Admin)

| Вопрос | Ответ |
|----------|-----------|
| Можно ли иметь несколько ролей? | Да, разрешения объединяются |
| Можно ли переименовать материал? | Да, но рекомендуется создать новый и устарить старый |
| Что если закрыть заявку без теста? | Система проверит правило BR-12 |
| Можно ли экспортировать весь каталог? | Да, через **Материалы** → **Экспорт** |
| Как проверить, кто что сделал? | **Аудит** в деталях заявки/работы/материала |
