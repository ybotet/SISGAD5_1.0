# Оперативное руководство (SISGAD5)

> **Версия:** 1.0
> **Аудитория:** Операторы, Техники полевые
> **Последнее обновление:** Сентябрь 2026

---

## 1. Введение

Это руководство предназначено для операторов (которые регистрируют заявки и управляют MP) и техников (которые выполняют тесты и полевые работы).

## 2. Доступ к системе

### 2.1. Вход

1. Перейти по корпоративному URL: `https://sisgad5.tuempresa.com`
2. Ввести email и пароль
3. Если первый вход — следовать инструкциям email приветствия
4. Выбрать "Запомнить сессию" только на личных защищённых устройствах

### 2.2. Восстановление пароля

1. На странице входа → **¿Забыли пароль?**
2. Ввести зарегистрированный email
3. Проверить почту → Кликнуть по ссылке
4. Ввести новый пароль (минимум 8 символов, включая число и букву)

## 3. Для операторов

### 3.1. Регистрация заявки

#### Шаг 1: Навигация
- Боковое меню → **MP** → **Заявки** → **Новая заявка**

#### Шаг 2: Классификация
Заполнить все поля:
- **Тип заявки** (Falla de Señal, Corte de Cable и т.д.)
- **Сервис** (telefonía, internet и т.д.)
- **Локация** (sector, municipio)
- **Ключ** (номер телефона/линии/панели подключения)

> **Примечание:** Приоритет рассчитывается автоматически. Если приоритет 1 (срочная), уведомление отправляется немедленно.

#### Шаг 3: Подтверждение
- Проверить данные
- Кликнуть **Создать**
- Записать номер заявки (напр. 1001), который появляется на экране

```
[ Пример экрана ]
Заявка успешно создана
Номер заявки: 1001
Приоритет: 2 - Средняя
Текущее состояние: Reportada → Priorizada → Abierta
```

### 3.2. Просмотр и поиск заявок

#### Список
- Меню → **MP** → **Заявки** → **Список**
- Колонки: № заявки, Приоритет, Тип, Сервис, Статус, Техник, Дата

#### Фильтры
- Статус (Abierta, En Progreso, Cerrada, Pendiente)
- Приоритет (1-4)
- Сервис
- Дата (с/по)
- Техник назначенный
- Свободный текст (поиск по описанию, ключу и т.д.)

### 3.3. Просмотр деталей заявки

#### Отображаемая информация
- Данные классификации (тип, сервис, локация, ключ)
- Рассчитанный приоритет и обоснование
- Текущее состояние и история изменений
- Назначенный техник
- Зарегистрированные тесты (если есть)
- Связанные работы (если есть)
- Кнопка: **Просмотр аудита** (кто что и когда делал)

#### Доступные действия (в зависимости от роли и состояния)
| Состояние | Оператор может |
|--------|---------------|
| Reportada/Priorizada | - |
| Abiertа | Просматривать, назначать тест, менять статус (если FSM допустим) |
| En Progreso | Просматривать, регистрировать тест, менять статус |
| Cerrada | Переоткрыть |
| Pendiente Prueba | Просматривать, регистрировать тест |

### 3.4. Регистрация теста

**Когда:** После выполнения измерения на месте.

#### Форма
- **Queja ID:** Предварительно выбрано при открытии из деталей заявки
- **Trabajo ID:** Необязательно (если связана с работой)
- **Resultado:** ✅ Успешный / ❌ Неуспешный
- **Mediciones:** JSON со значениями (latency, packet loss, signal и т.д.)
- **Observaciones:** Свободный текст

> **Важно:** Если тест неуспешен, заявка возвращается в состояние "En Progreso" и требуется повторный тест.

### 3.5. Управление инфраструктурой

#### Телефоны
- **Список:** Меню → **MP** → **Инфраструктура** → **Телефоны**
- **Создать:** Форма с номером, клиентом, локацией
- **Редактировать:** Изменить данные, статус (активен/в архиве)
- **Архив:** Отметить как "в архиве" с датой, не удалять

#### Линии
- Похоже на телефоны

#### Панели
- Список → Просмотр портов → Просмотр коннекторов
- При создании панели: указать физическое расположение и GPS-координаты

## 4. Для техников

### 4.1. Просмотр моих назначений

#### Заявки назначенные
- Меню → **Техник** → **Мои заявки**
- Отображает: номер заявки, приоритет, классификация, статус
- Цвет: Приоритет 1 = красный, Приоритет 2 = оранжевый

#### Работы назначенные
- Меню → **Техник** → **Мои работы**
- Отображает: номер ОТ, описание, исходная заявка, статус, оценочное/реальное время

### 4.2. Выполнение работы

#### Начать
1. Открыть назначенную работу
2. Кликнуть **Начать** (регистрирует время начала в полевых условиях)

#### Регистрация расхода
1. В деталях работы → вкладка **Расход материалов**
2. Для каждого материала:
   - Выбрать из каталога
   - Количество использованного
   - Единичная цена реальная (автозаполняется при совпадении)
3. Кликнуть **Сохранить** (проверяет запасы и лимиты назначения)

> **Правило:** Нельзя расродить больше, чем назначено. Система блокирует при превышении.

#### Закрытие работы
1. Завершить все пункты
2. Ввести **реальное время** (часы)
3. Кликнуть **Закрыть**
4. Реальное время не должно превышать 2× оценочное (правило BR-07)

### 4.3. Регистрация теста (от техника)
1. Открыть заявку → вкладка **Тесты**
2. Кликнуть **Новый тест**
3. Заполнить результаты и измерения
4. Кликнуть **Сохранить**

## 5. Коды состояний и приоритетов

### Состояния заявки

| Состояние | Цвет | Описание |
|--------|-------|-------------|
| Reportada | Серый | Создана, ожидает классификации |
| Priorizada | Синий | Система рассчитала приоритет |
| Abierta | Светло-синий | Готова к назначению |
| En Progreso | Оранжевый | Техник назначен |
| Pendiente Prueba | Жёлтый | Требуется тест |
| Prueba Exitosa | Зелёный | Тест пройден |
| Cerrada | Тёмно-зелёный | Разрешена |
| Cancelada | Красный | Отменена |

### Приоритеты

| Приоритет | Цвет | SLA максимальное |
|-----------|-------|------------|
| 1 - Срочная | Красный | 2 часа |
| 2 - Высокая | Оранжевый | 8 часов |
| 3 - Средняя | Жёлтый | 24 часа |
| 4 - Низкая | Зелёный | 72 часа |

## 6. Часто задаваемые вопросы (оперативные)

| Вопрос | Ответ |
|----------|-----------|
| Могу ли я менять статус заявки? | Только допустимые переходы FSM (см. техническое руководство) |
| Что если закрыть работу с очень высоким реальным временем? | Система предупредит, если превысит 2× оценочное, но разрешит сохранить |
| Могу ли я расходить материалы без работы? | Нет, всегда должны быть связаны с заказом |
| Как посмотреть мою историю работ? | Меню → **Техник** → **История** |
| Что означает "заблокировано" красным? | Вы попытались сделать то, что FSM не разрешает |
