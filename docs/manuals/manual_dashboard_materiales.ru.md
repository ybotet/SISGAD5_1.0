## 1. Доступ

1. Перейти по адресу: `https://sisgad5.tuempresa.com/materiales/dashboard`
2. Дашборд обновляется **автоматически** каждые 30 секунд
3. Использовать фильтры для сегментации данных

## 2. Доступные KPIs

### Панель 1: Агрегированные метрики

| Метрика | Описание | Формула |
|---------|-------------|---------|
| Asignaciones/Месяц | Всего назначений создано | COUNT(asignaciones) GROUP BY mes |
| Consumos/Месяц | Всего расходов зарегистрировано | COUNT(consumos) GROUP BY mes |
| Costo Total | Сумма всех расходов | SUM(consumo_items.costo_real) |
| Saldo Lógico Promedio | Средний баланс | AVG(Σ_asignado - Σ_consumido) |
| Alertas Stock Bajo | Материалы с балансом < минимума | COUNT WHERE saldo < stock_minimo |

### Панель 2: Распределение по категориям
- Столбчатая диаграмма: количество и стоимость по категориям
- Наведение для деталей: название, количество, средняя цена

### Панель 3: Топ-10 материалов
- Материалы с наибольшим расходом (количество)
- Колонки: Название, Количество, Общая стоимость, Текущий запас

### Панель 4: Низкий запас (Оповещения)

| Материал | Минимальный запас | Логический баланс | Дефицит |
|----------|---------------------|-------------------|---------|
| Cable CAT6 UTP | 100 | 45 | -55 |
| Conector RJ45 | 50 | 12 | -38 |

**Действие:** Клик по материалу → Просмотр деталей и истории → [К справочнику оператора](manual_operativo.ru.md)

## 3. Как использовать фильтры

### Диапазон дат
- Календарный выбор: "Последние 7 дней", "Последние 30 дней" или произвольный диапазон

### По технику
- Выпадающий список с техниками
- Фильтрует все KPIs по назначенному технику

### По категории
- Фильтр по категории материалов (Кабель, Коннекторы, Строительные материалы и т.д.)

## 5. Интерпретация метрик

### Логический баланс (Saldo Lógico)
- **Формула:** Σ(количества назначено) - Σ(количества расходовано)
- **Оптимальное состояние:** ≥ 0
- **Оповещение:** < stock_mínimo (красный цвет)
- **Отрицательный запас:** Указывает на перерасход (требует расследования)

### Стоимость момента vs Стоимость реальная
- **Стоимость момента:** Цена на момент назначения (заморожена)
- **Стоимость реальная:** Цена на момент расхода
- **Разница:** Изменение цен между назначением и расходом

## 6. Оповещения

Дашборд генерирует визуальные оповещения:
- 🔴 **Критический запас:** Баланс < 50% от минимума
- 🟡 **Низкий запас:** Баланс < минимум
- 🟢 **Запас OK:** Баланс ≥ минимум

## 7. Устранение неполадок

| Проблема | Причина | Решение |
|----------|-------|----------|
| Дашборд пустой | Нет данных за период | Расширить диапазон дат |
| Отрицательный запас | Расход > назначение | Проверить BR-08 |
| KPIs не обновляются | Redis кэш не истёк | Принудительная перезагрузка (Ctrl+F5) |
| Экспорт завершается ошибкой | Данные слишком большие | Сужать диапазон дат |
