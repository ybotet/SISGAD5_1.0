## 1. Термины домена MP (Телекоммуникации)

| Термин | Термин (RU) | Определение | Контекст | Синонимы |
|--------|-------------|-------------|----------|----------|
| **Телефон** | Телефон | Терминальное устройство абонента, подключенное к сети. | MP Service | Терминал, Абонент |
| **Линия** | Телефонные линии | Физическая среда или виртуальный канал, соединяющий абонентский терминал (телефон) с АТС, обеспечивая передачу голоса и данных. | MP Service | Канал, Пара |
| **Панель** | Учрежденческая АТС (УАТС) / Мини-АТС | Оборудование коммутации/соединения (MDF/IDF). | MP Service | Распределительный кадр, MDF, IDF |
| **Порт** | Порт | Физическая точка подключения на панели. | MP Service | Коннектор |
| **Жалоба** | Заявка / Заявка абонента | Официальное уведомление от клиента (обычно по телефону) о повреждении услуги. Точка входа в процесс управления неисправностями. | MP Service | Инцидент, Отчет, Тикет |
| **Испытание** | Станционная проверка | Техническая проверка элемента (телефон/линия/панель). | MP Service | Тест, Замер |
| **Работа** | Выездные работы | Приказ выполнения задач в полевых условиях (установка, ремонт, техобслуживание). | MP Service | Рабочий заказ, РЗ |
| **Ключ** | Ключ | Код классификации жалобы (тип/сервис/локация). | MP Service | Код, Классификатор |
| **Классификация** | Классификация | Категоризация жалобы по типу, сервису, локации. | MP Service | Типификация |
| **Приоритет** | Приоритет | Уровень срочности (1=Критический, 2=Высокий, 3=Средний, 4=Низкий). | MP Service | Срочность, Уровень |
| **Статус жалобы** | Статус заявки | Открыта→Проверена→Назначена→Ожидает→Решена→Закрыта. | MP Service | Конечный автомат |
| **Техник** | Техник | Полевой персонал, выполняющий испытания и работы. | MP Service | Оператор, Специалист |
| **Перемещение** | Перемещение | Физическое изменение элемента (установка, переезд, удаление). | MP Service | Переезд, Изменение |
| **Повреждение** | Повреждение / Авария | Полное или частичное прекращение предоставления телекоммуникационной услуги, зарегистрированное по заявке клиента или обнаруженное системой мониторинга. | MP Service | Рота, Аффекция |
| **Матrica de Quejas** | Журнал учета заявок | Устаревшее приложение на базе Microsoft Access, используемое DAG5 для оперативного управления. | MP Service | Система управления |
| **Orden de Servicio** | Наряд-заказ / Заказ-наряд | Официальный документ, выданный коммерческим отделом, разрешающий выполнение конкретных работ (установка, ремонт, техобслуживание) по услуге. | MP Service | Рабочий заказ |
| **Recorrido** | Трасса / Маршрут прокладки | Физический путь прохождения инфраструктуры связи (кабели, канализация) от АТС до конечной точки абонента. | MP Service | Трасса |

## 2. Термины домена Материалы

| Термин | Термин (RU) | Определение | Контекст | Синонимы |
|--------|-------------|-------------|----------|----------|
| **Материал** | Материалы / Расходные материалы | Элемент каталога с кодом, названием, ценой, единицей. Инструменты, расходные материалы и оборудование (кабели, терминалы, коннекторы), используемые специалистами для выполнения ремонтных или монтажных работ на линии. | Materials Service | Статья, Расходник, Средство |
| **Категория** | Категория | Логическая группа материалов (напр. Кабель, Коннектор, Инструмент). | Materials Service | Семейство, Группа |
| **Единица измерения** | Единица измерения | Величина количества (м, шт, кг, коробка). | Materials Service | UoM, Единица |
| **Назначение** | Назначение исполнителя | Выдача материалов технику/работе (цена в момент). | Materials Service | Выдача, Набор |
| **Расход** | Расход | Фактическое использование материалов в работе (реальная цена, ≤ назначено). | Materials Service | Расход, Использование |
| **Логический склад** | Логический склад | Σ(Назначено) − Σ(Расходовано) по технику/материал. | Materials Service | Баланс, Доступно |
| **Цена в момент** | Цена в момент | Цена за единицу, зафиксированная при создании назначения. | Materials Service | Замороженная цена |
| **Цена реальная** | Цена реальная | Цена за единицу, зафиксированная при регистрации расхода. | Materials Service | Цена исполнения |

## 3. Термины домена Пользователи и Безопасность

| Термин | Термин (RU) | Определение | Контекст | Синонимы |
|--------|-------------|-------------|----------|----------|

| **Разрешение** | Разрешение | Авторизованное действие над ресурсом (создать, прочитать, обновить, удалить). | Users Service | Привилегия, Privilege |

| **Сессия** | Сессия | Активная пара access+refresh token с метаданными (IP, user-agent). | Auth | Session |
| **RBAC** | Управление ролями | Управление доступом на основе ролей (Role-Based Access Control). | Auth | Управление ролями |

## 5. Технические и архитектурные термины

| Термин | Термин (RU) | Определение | Контекст |
|--------|-------------|-------------|----------|
| **API Gateway** | API шлюз | Единая точка входа, маршрутизация, auth, rate limiting. | Архитектура |
| **Микросервис** | Микросервис | Независимо развёртываемый сервис (Users, MP, Materials, Prediction). | Архитектура |
| **БД на сервис** | БД на сервис | Каждый микросервис имеет свою PostgreSQL (bd_users, bd_mp, bd_materiales, bd_predictions). | Данные |
| **Транзакция ACID** | Транзакция ACID | Атомарность, Согласованность, Изолированность, Долговечность (Go: db.Transaction). | Данные |
| **Конкуренция Go** | Конкуренция Go | Goroutines + WaitGroup + Channels для параллельной проверки. | Materials Service |
| **OpenAPI 3.0** | OpenAPI 3.0 | Спецификация REST-контрактов (YAML). | Контракты |
| **Swagger UI** | Swagger UI | Интерактивная документация из OpenAPI. | Контракты |
| **Распределённая блокировка** | Распределённая блокировка | Redis SETNX + TTL для конкуренции. | Materials Service |
| **Конечный автомат** | Конечный автомат | FSM (жалобы: Открыта→Проверена→Назначена→...). | MP Service |
| **Валидация spec** | Валидация spec | Валидация с Zod (Node.js) / Pydantic (Python). | Входные параметры API |
| **Структурированное логирование** | Структурированное логирование | Детальные записи всех действий в системе, включая информацию о том, кто, когда и какое действие выполнил (Pino/Zap/Winston). | Аудит |
| **Только чтение** | Только чтение | Сервис, потребляющий API других, не пишет в их БД. | Prediction Service |
| **DSS** | СППР | Система поддержки принятия решений: анализ исторических данных, визуализация (графики, дашборды) и генерация отчетов. | Архитектура |
| **Дашборд** | Дашборд | Визуальный интерфейс с графиками и показателями в реальном времени для мониторинга KPI. | Frontend |
| **Уведомление** | Уведомление | Автоматическое сообщение (email, SMS, уведомление в системе), отправляемое при критическом событии. | Система |

## 6. Термины KPIs и Метрик

| Термин | Термин (RU) | Определение | Контекст |
|--------|-------------|-------------|----------|
| **Услуга восстановлена за 24/72 часа** | Услуга восстановлена за 24/72 часа | KPI, измеряющий процент повреждений, устраненных в течение 24 или 72 часов с момента регистрации заявки. | KPI |
| **Неустраненное повреждение** | Неустраненное повреждение | Повреждение, зарегистрированное, но еще не устраненное. Измеряется как среднее количество незакрытых заявок на конец дня. | KPI |
| **Устраненное повреждение** | Устраненное повреждение | Повреждение, которое было устранено путем станционной проверки или выездных ремонтных работ. | KPI |
| **Повторное повреждение** | Повторное повреждение | Повреждение, возникающее повторно на той же услуге в течение короткого периода. Может указывать на неполное устранение. | KPI |
| **MTTR** | Среднее время восстановления (MTTR) | Среднее время между регистрацией повреждения и его устранением. | KPI |
| **MTBF** | Средняя наработка на отказ (MTBF) | Среднее время, в течение которого услуга работает без перебоев между двумя последовательными повреждениями. | KPI |
| **Жизненный цикл повреждения** | Жизненный цикл повреждения | Этапы: зарегистрировано → на диагностике → в ремонте → устранено → закрыто. | Процесс |

## 9. Глоссарий DDD (Domain-Driven Design)

### Сущности (Entities)

| Сущность | ID | Контекст | Описание |
|---------|----|----------|----------|
| **Пользователь** | `id` (UUID) | Users | Аккаунт с email, hash, ролями |
| **Жалоба** | `id` (serial) | MP | Инцидент с конечным автоматом и приоритетом |
| **Работа** | `id` (serial) | MP | Рабочий заказ с назначенным техником |
| **Материал** | `id` (serial) | Materials | Статья с кодом, названием, запасами |
| **Назначение** | `id` (serial) | Materials | Выдача материалов технику |
| **Расход** | `id` (serial) | Materials | Фактическое использование материалов |

### Объекты-значения (Value Objects)

| Значение | Контекст | Описание |
|---------|----------|----------|
| **Email** | Users | Проверен на email-формат, уникален |
| **Пароль** | Users | Hash с bcrypt, политика сложности |
| **Приоритет** | MP | Оценка (1-4) |
| **Статус жалобы** | MP | Enum конечного автомата |
| **Цена** | Materials | Decimal с 4 целыми, 2 десятичными цифрами |
| **Количество** | Materials | Положительное целое число |

### Агрегаты (Aggregates)

| Агрегат | Корневая сущность | Сущности/Значения | Контекст |
|---------|-------------------|-------------------|----------|
| **Пользователь** | Пользователь | Email, Rol, Permiso | Users |
| **Жалоба** | Жалоба | Классификация, Приоритет, Статус, Техник | MP |
| **Работа** | Работа | Жалоба (ref), Техник, Время | MP |
| **Материал** | Материал | Categoria, Unidad, Stock | Materials |
| **Назначение** | Назначение | Материал (ref), Cantidad, Precio в момент | Materials |
| **Расход** | Расход | Материал (ref), Cantidad, Precio real | Materials |

### События домена (Domain Events)

| Событие | Агрегат | Описание |
|--------|---------|----------|
| `UsuarioCreado` | Пользователь | Новый пользователь зарегистрирован |
| `QuejaReportada` | Жалоба | Жалоба создана с начальной классификацией |
| `QuejaReasignada` | Жалоба | Смена назначенного техника |
| `QuejaCerrada` | Жалоба | Статус → Закрыта, инициирует расход материалов |
| `TrabajoCreado` | Работа | Рабочий заказ связан с жалобой |
| `MaterialAsignado` | Назначение | Материал выдан технику |
| `StockDecrementado` | Материал | Запас уменьшен расходом |
| `PrediccionGenerada` | Prediction | Новое предсказание зарегистрировано в bd_predictions |
