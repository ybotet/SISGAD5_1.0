## 1. Термины домена MP (Телекоммуникации)

| Термин | Определение | Контекст | Синонимы |
|--------|-------------|----------|----------|
| **Телефон** | Терминальное устройство абонента, подключенное к сети | MP Service | Терминал, Абонент |
| **Линия** | Канал связи между станцией и абонентом | MP Service | Канал, Пара |
| **Панель** | Оборудование коммутации/соединения (MDF/IDF) | MP Service | Распределительный кадр, MDF, IDF |
| **Порт** | Физическая точка подключения на панели | MP Service | Коннектор |
| **Жалоба** | Запись инцидента, сообщенного клиентом/оператором | MP Service | Инцидент, Отчет, Тикет |
| **Испытание** | Техническая проверка элемента (телефон/линия/панель) | MP Service | Тест, Замер |
| **Работа** | Приказ выполнения задач в полевых условиях | MP Service | Рабочий заказ, РЗ |
| **Ключ** | Код классификации жалобы (тип/сервис/локация) | MP Service | Код, Классификатор |
| **Классификация** | Категоризация жалобы по типу, сервису, локации | MP Service | Типификация |
| **Приоритет** | Уровень срочности (1=Критический, 2=Высокий, 3=Средний, 4=Низкий) | MP Service | Срочность, Уровень |
| **Статус жалобы** | Открыта→Проверена→Назначена→Ожидает→Решена→Закрыта | MP Service | Конечный автомат |
| **Техник** | Полевой персонал, выполняющий испытания и работы | MP Service | Оператор, Специалист |
| **Перемещение** | Физическое изменение элемента (установка, переезд, удаление) | MP Service | Перемещение, Изменение |

## 2. Термины домена Материалы

| Термин | Определение | Контекст | Синонимы |
|--------|-------------|----------|----------|
| **Материал** | Элемент каталога с кодом, названием, ценой, единицей | Materials Service | Статья, Расходник, Средство |
| **Категория** | Логическая группа материалов (напр. Кабель, Коннектор, Инструмент) | Materials Service | Семейство, Группа |
| **Единица измерения** | Величина количества (м, шт, кг, коробка) | Materials Service | UoM, Единица |
| **Назначение** | Выдача материалов технику/работе (цена в момент) | Materials Service | Выдача, Набор |
| **Расход** | Фактическое использование материалов в работе (реальная цена, ≤ назначено) | Materials Service | Расход, Использование |
| **Логический склад** | Σ(Назначено) − Σ(Расходовано) по технику/материал | Materials Service | Баланс, Доступно |
| **Цена в момент** | Цена за единицу, зафиксированная при создании назначения | Materials Service | Замороженная цена |
| **Цена реальная** | Цена за единицу, зафиксированная при регистрации расхода | Materials Service | Цена исполнения |
| **Исполнитель** | Техник, получающий назначения и регистрирующий расходы | Materials Service | Оператор, Пользователь материалов |

## 3. Термины домена Пользователи и Безопасность

| Термин | Определение | Контекст | Синонимы |
|--------|-------------|----------|----------|
| **Пользователь** | Субъект, доступящийся к системе (email, password hash, роли) | Users Service | Аккаунт, Account |
| **Роль** | Набор разрешений (Admin, Tecnico, Operador, Jefe, Analista, Director, Auditor) | Users Service | Профиль, Profile |
| **Разрешение** | Авторизованное действие над ресурсом (создать, прочитать, обновить, удалить) | Users Service | Привилегия, Privilege |
| **Access Token** | JWT короткого действия (15 мин) для авторизации запросов | Auth | Токен доступа |
| **Refresh Token** | Долгоживущий токен (7 дней) для обновления access token | Auth | Токен обновления |
| **Сессия** | Активная пара access+refresh token с метаданными (IP, user-agent) | Auth | Session |
| **RBAC** | Управление доступом на основе ролей (Role-Based Access Control) | Auth | Управление ролями |

## 4. Термины домена Prediction Service (MLOps)

| Термин | Определение | Контекст | Синонимы |
|--------|-------------|----------|----------|
| **Прогноз** | Оценка, основанная на ML-модели для конкретного случая | Prediction Service | Оценка, Прогноз |
| **Признак** | Входная переменная, обработанная для ML-модели | Prediction Service | Фича, Входной признак |
| **Инжиниринг признаков** | Процесс преобразования данных в признаки | Prediction Service | Feature Engineering |
| **Модель** | Обученный алгоритм (scikit-learn, XGBoost, Prophet) | Prediction Service | ML-модель |
| **Обучение** | Процесс настройки параметров модели на исторических данных | Prediction Service | Training |
| **Переобучение** | Периодическое обновление модели новыми данными | Prediction Service | Retraining |
| **Реестр моделей** | Версионированное хранилище обученных моделей (MLflow) | MLOps | Model Registry |
| **Конвейер** | Последовательность трансформаций и обучения (Airflow DAG) | MLOps | Тренировочный конвейер |
| **Дрифт** | Ухудшение производительности модели со временем | MLOps | Отклонение, Concept Drift |
| **Инференс** | Применение модели к новым данным | Prediction Service | Inference |
| **Метрика** | Метрика оценки (MAE, RMSE, Точность, Точность, Полнота) | Prediction Service | Метрика |
| **bd_predictions** | Выделенная БД для предсказаний, метаданных и метрик | Prediction Service | Prediction DB |

## 5. Технические и архитектурные термины

| Термин | Определение | Контекст |
|--------|-------------|----------|
| **API Gateway** | Единая точка входа, маршрутизация, auth, rate limiting | Архитектура |
| **Микросервис** | Независимо развёртываемый сервис (Users, MP, Materials, Prediction) | Архитектура |
| **БД на сервис** | Каждый микросервис имеет свою PostgreSQL (bd_users, bd_mp, bd_materiales, bd_predictions) | Данные |
| **Транзакция ACID** | Атомарность, Согласованность, Изолированность, Долговечность (Go: db.Transaction) | Данные |
| **Конкуренция Go** | Goroutines + WaitGroup + Channels для параллельной проверки | Materials Service |
| **OpenAPI 3.0** | Спецификация REST-контрактов (YAML) | Контракты |
| **Swagger UI** | Интерактивная документация из OpenAPI | Контракты |
| **Распределённый блокировщик** | Redis SETNX + TTL для конкуренции | Materials Service |
| **Конечный автомат** | FSM (жалобы: Открыта→Проверена→Назначена→...) | MP Service |
| **Валидация spec** | Валидация с Zod (Node.js) / Pydantic (Python) | Входные параметры API |
| **Структурированное логирование** | JSON-логи с метаданными (Pino/Zap/Winston) | Аудит |
| **Только чтение** | Сервис, потребляющий API других, не пишет в их БД | Prediction Service |

## 7. Глоссарий DDD (Domain-Driven Design)

### Сущности (Entities)
| Сущность | ID | Контекст | Описание |
|---------|----|----------|----------|
| **Usuario** | `id` (UUID) | Users | Аккаунт с email, hash, ролями |
| **Жалоба** | `id` (serial) | MP | Инцидент с конечным автоматом и приоритетом |
| **Работа** | `id` (serial) | MP | Рабочий заказ с назначенным техником |
| **Материал** | `id` (serial) | Materials | Статья с кодом, названием, запасами |
| **Назначение** | `id` (serial) | Materials | Выдача материалов технику |
| **Расход** | `id` (serial) | Materials | Фактическое использование материалов |

### Объекты-значения (Value Objects)
| Значение | Контекст | Описание |
|---------|----------|----------|
| **Email** | Users | Проверен на email-формат, уникален |
| **Пароль** | Users | Hash с bcrypt, политика сложности |
| **Prioridad** | MP | Оценка (1-4) |
| **Статус жалобы** | MP | Enum конечного автомата |
| **Цена** | Materials | Decimal с 4 целыми, 2 десятичными цифрами |
| **Количество** | Materials | Положительное целое число |

### Агрегаты (Aggregates)
| Агрегат | Корневая сущность | Сущности/Значения | Контекст |
|---------|-------------------|-------------------|----------|
| **Пользователь** | Пользователь | Email, Rol, Permiso | Users |
| **Жалоба** | Жалоба | Классификация, Приоритет, Статус, Техник | MP |
| **Работа** | Работа | Жалоба (ref), Техник, Время | MP |
| **Материал** | Материал | Categoria, Unidad, Stock | Materials |
| **Назначение** | Назначение | Материал (ref), Cantidad, Precio в момент | Materials |
| **Расход** | Расход | Материал (ref), Cantidad, Precio real | Materials |

### События домена (Domain Events)
| Событие | Агрегат | Описание |
|--------|---------|----------|
| `UsuarioCreado` | Пользователь | Новый пользователь зарегистрирован |
| `QuejaReportada` | Жалоба | Жалоба создана с начальной классификацией |
| `QuejaReasignada` | Жалоба | Смена назначенного техника |
| `QuejaCerrada` | Жалоба | Статус → Закрыта, инициирует расход материалов |
| `TrabajoCreado` | Работа | Рабочий заказ связан с жалобой |
| `MaterialAsignado` | Назначение | Материал выдан технику |
| `StockDecrementado` | Материал | Запас уменьшен расходом |
| `PrediccionGenerada` | Prediction | Новое предсказание зарегистрировано в bd_predictions |
